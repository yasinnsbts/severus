## Ответы Андрея (14.11.2026)

1. `INNER-TIMING` считает группы по делению класса в плане и знает ограниченный набор формулировок; в этом прогоне одно из двух не совпало. Добавит правило «число групп из текста». Наша трасса подтверждает: `groups_count = 4` в плане, но фразы «У вас три минуты», «3 минуты на группу» и «остальных трёх групп» не входят в шаблоны.
2. 1612 год берётся из карточки каталога, но проверенной цитаты по Дню единства нет; без источника сервис запрещает исторические утверждения. Цитата про Минина и Пожарского есть в PR #27 Снежаны — после слияния модель сможет раскрыть историю.
3. Вертеп: источника нет, для демо пример убираем.
4. В контрольном запросе стояла подробность `detailed`, по умолчанию `standard`. Норму длины реплик для 1–4 классов всё равно снизят и добавят в промпт требование коротких предложений.

Следствие для QA: `SCRIPT-SHORT` в `c2`/`c3` получен на `detailed`, поэтому приоритет BUG-05 опирается на `variants_2` (`standard`). После слияния PR #27 перепрогнать `c2`; после доработки `INNER-TIMING` — `c2` и `variants_2`.
