## P2 — мешает качеству, есть обход

### BUG-16. Технический ID в реплике педагога

- **Что это за баг:** в текст для учителя попадает внутреннее имя материала вместо нормального описания.
- **Что видит пользователь:** `commitments_book_pages` в `teacher_script`.
- **Где:** `checks.py:424`; `timeline[].teacher_script`.
- **Подтверждение:** UI-прогон `job_f37a1bca82c04f2fa564b87863943ddc`, v2, `block_04`.
- **Статус:** материалы и часть реплик уже чистые; остались отдельные ID в блоках.

### BUG-20. `INNER-TIMING` ложно срабатывает на параллельной работе

- **Что это за баг:** проверка считает одновременную работу пар или следующего блока последовательными выступлениями и ругается на тайминг.
- **Пример 1:** `r02` v2 — 13 пар × 4 мин = 52 мин при блоке 10, хотя все пары работают параллельно.
- **Пример 2:** UI v1 — в 5-минутном блоке описана 15-минутная работа и выступления 5 групп, которые относятся к следующему блоку; проверка пишет «остаётся 0 мин».
- **Где:** `inner_timing.py`.
- **Подтверждение:** `job_20261114_185439_efcfb1` (v2), `job_f37a1bca82c04f2fa564b87863943ddc` (v1).

### BUG-21. Редкий schema-fail на 35 учениках с reasoning medium

- **Что это за баг:** модель иногда возвращает блок без обязательных `pupil_actions` и `role_ids`; после 3 попыток вариант падает.
- **Что видит пользователь:** `failed`, `VARIANT_GENERATION_FAILED`.
- **Где:** `scenario_block`, схема блока.
- **Подтверждение:** `job_c7df9e8e284441f181f5e78d48da4a27` — `failed`; повтор `job_a186e61612704276a7fa669721be95a7` — `completed`. Проблема плавающая.

### BUG-22. Три варианта с reasoning medium идут дольше 15 минут

- **Что это за баг:** 3 варианта занимают 17,3 минуты; тестовый клиент с таймаутом 900 с решил, что задание ещё `running`, хотя оно завершилось 3/3.
- **Что видит пользователь:** долгое ожидание, риск таймаута на клиенте.
- **Где:** пайплайн, лимиты времени; не ошибка генерации.
- **Подтверждение:** `job_7a0a4fdc1f3046f88e3f9dd3cbd74ff7`, `duration_ms=1 037 842`, 3/3 `completed`.
- **Ожидаемо:** либо уложиться в 15 минут, либо поднять клиентский таймаут и показать прогресс.
