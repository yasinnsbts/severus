## P1

### BUG-03. `INNER-TIMING` не ловит 4 группы × 3 минуты в блоке 10 минут

- **Владелец:** Андрей (валидатор), проверка — Максим
- **Где:** `services/school_events_llm/app/validation/checks.py`, `inner_timing_problems`.
- **Шаги:**
  1. Запустить `python -m app batch examples/requests/content_check`.
  2. Открыть `c2_unity_day_10_45.json`, блок 20–30 мин.
  3. Сверить `quality_report`.
- **Факт:** в блоке 20–30 минут четыре группы представляют результаты по 3 минуты: 4 × 3 = 12 минут при бюджете 10. В `quality_report` только `SCRIPT-SHORT`, `INNER-TIMING` нет.
- **Ожидаемо:** `INNER-TIMING` уровня `warning` с расчётом 12 > 10.
- **Влияние:** сценарий с нереалистичным таймингом проходит автоматику; эксперт обязан поймать вручную.
- **Примечание:** на старом сценарии `labour_day` механизм срабатывал, но не покрывает формулировку «Группа номер один… у вас три минуты» без «на группу».

## P2

### BUG-06. Формат issue не соответствует ТЗ 16.2

- **Владелец:** Андрей (сервис) + Максим (QA-модуль)
- **Где:** QA-модуль (`code / severity / message / field`), сервис (`code / severity / location / message`).
- **Факт:** в ТЗ есть `issue_id`, `category`, `repairable`, `suggested_action`.
- **Ожидаемо:** единый формат и маппинг.
- **Влияние:** два формата усложняют обработку замечаний.

### BUG-12. В форме нет режима участия родителей

- **Владелец:** Оля (фронтенд)
- **Где:** `frontend/src/App.tsx`, блок «Участники и пространство».
- **Факт:** роли родителей выбрать можно, но поля `parent_audience_engagement` нет. Форма всегда отправляет значение по умолчанию, поэтому нельзя запросить голосование, обратную связь или награду.
- **Ожидаемо:** выбор режима участия, как в контракте 01 (ТЗ 6.2–6.4).
- **Влияние:** сценарии с голосованием и наградой через UI не воспроизводятся; fixture-эталон с `audience_award` не проходит.

### BUG-13. В сценарии заявлены события 1612 года, но исторического блока нет

- **Владелец:** Андрей (генерация) + Снежана (содержание)
- **Где:** `c2_unity_day_10_45`, День народного единства, 10 класс.
- **Факт:** в задачах написано «знакомство с событиями 1612 года», но ни один блок не раскрывает историю; сценарий посвящён традициям народов.
- **Ожидаемо:** либо исторический блок, либо задача без обещания 1612 года.
- **Влияние:** заявленная образовательная цель не достигается.

### BUG-05. `SCRIPT-SHORT` требует калибровки

- **Владелец:** Андрей (порог), решение — Ярослав
- **Где:** `script_length.py`, `checks.py`.
