## P1 — ломает пользовательский путь

### BUG-14. Сценарий с жюри падает с `JURY-SCORECARD`

- **Что видит пользователь:** задание `failed`, сценарий не создан. E2E-16 «Праздник Весны и Труда», 10 класс, 60 минут, родители-оценщики.
- **Где ломается:** `services/school_events_llm/app/validation/checks.py:351`. Проверка ищет `jury_scorecard` только в `materials[].type`.
- **Причина:** модель создаёт материал `material_id="jury_scorecard"` с корректным листом критериев, но ставит `type="quiz"`. Проверка считает, что листа нет, и выдаёт `critical`.
- **Ожидаемо:** принимать лист по `material_id` или нормализовать `type` по `material_id`. Ремонт не должен тратить два вызова и падать.
- **Подтверждение:** `data/runs/job_2dfc94e57e84454f8316660c8d51f60d` (`validation.json`, `variant_package.json`).

## P2 — мешает качеству, есть обход

### BUG-17. `PARENTS-OVER`: родителей больше, чем запрошено

- **Что видит пользователь:** из двух вариантов остаётся один, задание `partial`; в UI одна вкладка вместо двух.
- **Где ломается:** планирование ролей + `checks.py:317`. При 12 родителях и ролях `helper` + `audience` модель создаёт 12 помощников и 1 зрителя — 13 в одном блоке.
- **Ожидаемо:** сумма родителей в блоке ≤ `parents_count`; например 11 помощников + 1 зритель.
- **Подтверждение:** `data/runs/job_3220de56ecc24792afee1786cbb14b41` (`variants/v1/validation.json`).

### BUG-13. 1612 год заявлен, исторического блока нет

- **Что видит пользователь:** в задачах «знакомство с событиями 1612 года», в сценарии истории нет.
- **Где ломается:** `unity_day`; в PR #30 фрагменты `catalog/sources/unity_day.json` имеют статус `draft`, проверенных цитат нет.
- **Ожидаемо:** после PR #27 — исторический блок; до слияния — не заявлять 1612 год в задачах.
- **Подтверждение:** `q01`/`q02` без PR #27 — `GOAL-UNCOVERED`; `job_20261114_143202_0dbaf1`, `job_20261114_143305_7ed322`.

### BUG-09. Нет памятки для родителей-помощников

- **Что видит пользователь:** родители-помощники есть, материала `parent_instruction` нет.
- **Где ломается:** `checks.py:347`; воспроизводится в `variants_3`, варианты 2 и 3.
- **Ожидаемо:** при роли `helper` памятка создаётся всегда.
- **Подтверждение:** `data/runs/job_62fb272022d64997b1939c994210e975`.

### BUG-12. В форме нет режима участия родителей

- **Что видит пользователь:** нельзя выбрать голосование, обратную связь или награду.
- **Где ломается:** `frontend/src/App.tsx`, блок «Участники и пространство»; поля `parent_audience_engagement` нет, форма шлёт значение по умолчанию.
- **Ожидаемо:** выбор режима по ТЗ 6.2–6.4.

### BUG-15. Форма по умолчанию включает `detailed`

- **Что видит пользователь:** обычная генерация идёт в подробном режиме, реплики длиннее и дороже.
- **Где ломается:** `frontend/src/App.tsx:93`: `script_detail: 'detailed'`; серверный/default — `standard`.
- **Ожидаемо:** `standard` по умолчанию.
- **Владелец:** Оля.

### BUG-16. Технические ID в тексте для педагога

- **Что видит пользователь:** в инструкциях и примечаниях `teacher_fallback`, `colored_papers`.
- **Где ломается:** `checks.py:424`; источники — `teacher_instructions` и `materials[].teacher_notes`.
