## 4. Что подтвердилось

- **BUG-03 закрыт:** старое `4 группы × 3 минуты` в 10-минутном блоке теперь ловится; живой E2E-07 подтвердил на новой сборке.
- **BUG-13 не закрыт:** без PR #27 `q01` и `q02` (`unity_day`) дают `GOAL-UNCOVERED`: «1612» не упоминается ни в одном этапе и материале; исторического блока нет. Проверено на `job_20261114_143202_0dbaf1` и `job_20261114_143305_7ed322`.
- **Вертеп:** в `q03` (Рождество, 7 класс) пример убран, `CULTURE-UNSOURCED` больше нет.
- **1–4 классы:** коэффициент 0,7 убрал `SCRIPT-SHORT` в `q05` (2 класс).
- **standard 5–8:** `q02` без PR #27 прошёл без `SCRIPT-SHORT`; осталось только `GOAL-UNCOVERED` по 1612 году.

## 5. Дефекты

Новые и возвращённые:

- **BUG-14 (P1):** `JURY-SCORECARD` валит валидный сценарий с жюри: материал `jury_scorecard` создан, но с `type: "quiz"`; проверка ищет только `type` и выдаёт `critical`.
- **BUG-15 (P2):** UI по умолчанию отправляет `script_detail=detailed` вместо `standard`.
- **BUG-16 (P2):** в текст для педагога попадают `teacher_fallback` и `colored_papers`.
- **BUG-17 (P2):** `PARENTS-OVER`: при 12 родителях и ролях helper + audience модель создаёт 13 (12+1), вариант падает, задание становится `partial`.
- **BUG-09 (P2, возвращён):** при родителях-помощниках не всегда создаётся памятка (`PARENT-INSTRUCTION`).
- **BUG-11 (P3, возвращён):** `FACT-UNREGISTERED` на даты, не попавшие в `fact_claims`: 1700, 2008, 2023.
- **BUG-13 (P2, остаётся):** 1612 год заявлен в задачах, но проверенных фрагментов в PR #30 нет; без PR #27 исторического блока нет.

Остаются: BUG-04, BUG-05, BUG-06, BUG-07, BUG-12, BUG-13.

## 6. UI-регрессия

Запуск: `node qa/tests/ui/regression.mjs` на `http://127.0.0.1:5173`.

Основной прогон (12 родителей, роли helper + audience, 2 варианта):

- PASS: форма, API-режим, каталог из 14 событий, блокировка 36 учеников, POST 202.
- FAIL: «Два варианта отображаются» — вкладок 1, потому что вариант 1 упал с `PARENTS-OVER` (BUG-17), задание стало `partial`.
- Дальше сценарий остановился: второй вкладки нет, переключение вариантов недоступно.

Обходной прогон (те же 2 варианта, только роль «Помощники», без «Зрителей»):

- PASS: форма, API, каталог 14, блокировка 36, POST 202, два варианта, блоки этапов, переключение варианта, «Материалы» (6), «Участники» (3), копирование (9 605 символов), восстановление после F5 (2 вкладки), возврат к новому сценарию, запуск генерации, прогресс после F5.

Отдельно подтверждено по коду: поля `parent_audience_engagement` в форме нет (BUG-12), по умолчанию `script_detail` — `detailed` (BUG-15).
